# Электронный журнал группы

Веб-приложение для учёта студентов. Написано на PHP с использованием PDO, данные хранятся в базе SQLite.

## ✨ Возможности

- Просмотр списка студентов с названием группы (LEFT JOIN)
- Добавление нового студента через форму
- Редактирование данных студента
- Удаление студента с подтверждением
- Статистика по группам (GROUP BY)
- Защита от SQL-инъекций (prepared statements)
- Защита от XSS (`htmlspecialchars`)
- Красивый переливающийся пастельный дизайн

## 🛠️ Стек технологий

- **PHP 8.5** — на этой версии проект разработан и протестирован
- **SQLite** — база данных в одном файле
- **PDO** — подключение к БД через драйвер `pdo_sqlite`
- **DBeaver** — управление базой данных
- **VSCodium** — редактор кода

## 📋 Требования

- **PHP 8.5** (разработка и тестирование велись на этой версии)
- Минимально совместимая версия — **PHP 7.0**
- Расширения PHP:
  - `pdo_sqlite`
  - `sqlite3`
- Любая ОС: **Windows**, **macOS**, **Linux**

### О совместимости версий

Проект написан с использованием только базовых возможностей PHP и PDO, поэтому **должен работать на всех версиях PHP 7.x и 8.x**. Никакие «новые» синтаксические конструкции (стрелочные функции, `match`, nullsafe-оператор и т.п.) не применяются.

Тем не менее, если у вас **PHP 7.0–7.3**, поведение не гарантировано — эти версии давно не поддерживаются официально. Рекомендуется **PHP 8.0 и выше**.

## 🚀 Как запустить у себя

### Шаг 1. Установить PHP

#### Windows (пошагово)

**1.1. Скачать правильный архив**

1. Откройте https://windows.php.net/download/
2. Найдите блок **PHP 8.x (x.x.x)**.
3. Скачайте **Zip**-архив с пометкой **VS17 x64 Thread Safe**. Имя файла будет вида:
   ```
   php-8.5.10-Win32-vs17-x64.zip
   ```
   > ⚠️ **Важно:** в имени файла **не должно быть `-src`**. Архивы с `-src` — это исходный код, из него PHP не запускается.

**1.2. Распаковать**

1. Создайте папку `C:\php`.
2. Распакуйте туда содержимое архива так, чтобы файл `php.exe` лежал **прямо в `C:\php`**:
   ```
   C:\php\
      ├── php.exe          ← вот он
      ├── php.ini-development
      ├── php.ini-production
      ├── ext\
      └── ...
   ```
   Если распакуется папка `php-8.5.10-Win32-vs17-x64`, зайдите в неё и переместите содержимое в `C:\php`.

**1.3. Создать `php.ini`**

1. В `C:\php` найдите файл `php.ini-development`.
2. Скопируйте его и переименуйте копию в **`php.ini`** (без расширения `.txt`).
3. Откройте `php.ini` в блокноте, найдите через `Ctrl+F`:
   ```
   ;extension=pdo_sqlite
   ;extension=sqlite3
   ```
4. **Удалите точку с запятой** в начале каждой строки. Должно получиться:
   ```
   extension=pdo_sqlite
   extension=sqlite3
   ```
5. Сохраните файл.

**1.4. Добавить PHP в PATH**

1. Нажмите `Win + R`, введите `sysdm.cpl`, нажмите Enter.
2. Вкладка **Дополнительно** → кнопка **Переменные среды**.
3. В **верхнем** блоке («Переменные среды пользователя») найдите переменную **`Path`**.
4. Выделите её → **Изменить** → **Создать**.
5. Введите:
   ```
   C:\php
   ```
6. Нажмите **OK** во всех трёх окнах.

> ⚠️ Убедитесь, что редактируете именно **`Path`**, а не `ComSpec` — они рядом в списке. Если случайно изменили `ComSpec`, верните ей значение `C:\Windows\System32\cmd.exe`.

**1.5. Перезапустить терминал**

Это **обязательно**: изменения в PATH не видны уже открытым программам.

1. **Закройте VSCodium полностью** (File → Exit).
2. Откройте VSCodium заново.
3. Откройте терминал: **Terminal → New Terminal**.
4. Проверьте:
   ```powershell
   php -v
   ```
   Должны увидеть версию PHP:
   ```
   PHP 8.5.10 (cli) (built: ...) (ZTS Visual C++ 2022 x64)
   ```

**1.6. Проверить расширения SQLite**

```powershell
php -m | findstr sqlite
```

Должны появиться две строки:
```
pdo_sqlite
sqlite3
```

Если пусто — вернитесь к шагу 1.3 и убедитесь, что `php.ini` создан и расширения раскомментированы.

#### macOS

```bash
brew install php
```
Расширения `pdo_sqlite` и `sqlite3` идут в комплекте.

#### Linux (Debian/Ubuntu)

```bash
sudo apt update
sudo apt install php php-sqlite3
```

### Шаг 2. Скачать проект

**Вариант 1. Через Git** (если установлен):

```bash
git clone https://github.com/nessquish/electronic-journal.git
cd electronic-journal
```

**Вариант 2. Скачать Zip:**

1. Откройте репозиторий: `https://github.com/nessquish/electronic-journal`
2. Нажмите зелёную кнопку **Code** → **Download ZIP**.
3. Распакуйте архив.

### Шаг 3. Запустить сервер

Откройте терминал в папке проекта и введите:

```bash
php -S localhost:8000
```

Терминал выведет:
```
PHP 8.5.10 Development Server (http://localhost:8000) started
```

> ⚠️ Терминал **не закрывайте** — пока он работает, живёт сайт. Остановить — `Ctrl+C`.

### Шаг 4. Открыть в браузере

```
http://localhost:8000/
```

Готово — вы увидите страницу «Электронный журнал группы» с таблицей студентов, формой добавления и статистикой по группам.

## 📁 Структура проекта

```
electronic-journal/
├── config.php       # путь к базе данных
├── db.php           # функция getPDO() — подключение через PDO
├── index.php        # главная: список + добавление + удаление + статистика
├── edit.php         # редактирование студента
├── school.sqlite    # база данных SQLite
└── README.md        # этот файл
```

## 🗄️ Структура базы данных

| Таблица    | Назначение                           |
|------------|--------------------------------------|
| `groups`   | Учебные группы                       |
| `teachers` | Преподаватели                        |
| `subjects` | Дисциплины (со ссылкой на teacher)   |
| `students` | Студенты (со ссылкой на group)       |
| `grades`   | Оценки (студент + дисциплина + балл) |

Связь `students ↔ subjects` реализована через промежуточную таблицу `grades` (Many-to-Many).

## 🔐 Безопасность

- Все SQL-запросы с параметрами выполняются через `prepare()` + `execute([...])`
- Все выводимые данные оборачиваются в `htmlspecialchars()`
- Ошибки подключения обрабатываются через `try-catch` с `PDOException`
- После POST-запроса выполняется редирект (`header('Location: ...')`) — защита от повторной отправки формы

## 🆘 Решение проблем

### `php не является внутренней или внешней командой`

PHP не добавлен в PATH или терминал не перезапущен.

**Проверьте PATH:**

1. `Win + R` → `sysdm.cpl` → **Дополнительно** → **Переменные среды**.
2. В **«Переменных среды пользователя»** найдите `Path`.
3. Убедитесь, что там есть строка `C:\php`.
4. Если нет — **Изменить → Создать → `C:\php` → OK**.

**Перезапустите VSCodium полностью** (File → Exit) и откройте заново.

**Быстрая проверка без PATH** — запуск по полному пути:
```powershell
C:\php\php.exe -S localhost:8000
```

### `could not find driver`

Не включены расширения SQLite. Откройте `C:\php\php.ini` и раскомментируйте:
```
extension=pdo_sqlite
extension=sqlite3
```
Перезапустите сервер (`Ctrl+C`, затем снова `php -S localhost:8000`).

### `unable to open database file`

Файл `school.sqlite` не найден или лежит не рядом с PHP-файлами. Проверьте структуру:
```
electronic-journal/
├── config.php
├── db.php
├── index.php
├── edit.php
└── school.sqlite   ← здесь
```

### Белая страница или ошибка 500

Включите вывод ошибок — в самый верх `config.php` добавьте:
```php
ini_set('display_errors', 1);
error_reporting(E_ALL);
```
Перезагрузите страницу — увидите текст ошибки.

### Порт 8000 занят

Запустите сервер на другом порту:
```bash
php -S localhost:8080
```
И откройте http://localhost:8080/

### Кракозябры вместо русского текста

Проверьте кодировку PHP-файлов — должна быть UTF-8. В VSCodium внизу справа нажмите на кодировку → **Save with Encoding → UTF-8**.
